[이 폴더 안에 있는 파일/폴더가 각각 뭔지 설명하는 문서]
(코드를 몰라도 이해할 수 있게 쉽게 씀. 자세한 안전/실행 설명은 README.md 참고)


====================================================
■ 폴더 안 안 들어가고 맨 위에 그냥 놓여있는 파일들
====================================================

이 파일들은 전부 "실제로 웹앱을 켜는 데 필요한 것들"이라 폴더로 안 묶고
그냥 맨 위에 뒀어. 웹앱을 옮기거나 옮겨 받을 땐 이 파일들이 전부 같은
폴더 안에 있어야 함 (하나라도 빠지면 안 돌아감).

- index.html
    브라우저로 여는 "화면" 파일. 버튼, 카드, 글자 같은 화면 생김새와
    구조만 담당하고, 실제 동작(카메라 켜기, 계산, 아두이노로 신호 보내기
    등)은 안 함. 화면을 열면 이 파일이 app.js를 불러와서 실제 동작을 시킴.

- app.js
    이 프로젝트의 진짜 "두뇌"에 해당하는 파일. 카메라 영상 처리, 손/팔
    구부러진 정도 계산, 목표값과 실제값 비교, EMS 세기를 얼마나 올리고
    내릴지 계산, 아두이노로 시리얼 통신 보내기, 음성 비서("탱글이") 처리
    등 이 프로젝트의 실제 로직이 전부 이 파일 안에 있음(코드 한 4천 줄
    정도). 거울 모드/팔 인식 모드/행동 보조 모드/테스트 모드 4개 모드가
    다 이 파일 하나에 들어있음. index.html이 이 파일을 불러와서 실행시킴.

- hand_landmarker.task
- pose_landmarker_full.task
    ".task" 파일은 구글 MediaPipe가 배포하는 "AI 인식 모델" 파일임(코드가
    아니라 학습된 신경망 데이터). 우리가 만든 게 아니라 구글에서 다운받은
    것.
      · hand_landmarker.task  → 손가락 마디 위치를 인식하는 모델
      · pose_landmarker_full.task → 어깨/팔꿈치/손목 등 몸 전체 관절을
        인식하는 모델
    app.js가 실행될 때 이 파일들을 읽어서 "지금 화면에 손/팔이 어디
    있고 얼마나 구부러졌는지"를 계산함. (예전엔 더 가볍고 빠른 대신
    정확도가 낮은 pose_landmarker_lite.task도 같이 뒀었는데, full로 완전히
    바꾸면서 안 쓰는 파일이라 정리 과정에서 삭제함.)

- run_server.bat
    윈도우에서 더블클릭하면 이 폴더를 "웹서버"로 띄워주는 실행 파일
    (파이썬의 http.server 기능을 씀). 브라우저 카메라 권한 등 보안 정책
    때문에 index.html을 그냥 더블클릭해서 여는 것보다 이렇게 로컬
    서버로 여는 게 훨씬 안정적이라 이 방법을 씀. 실행하면 검은 창이
    뜨고, 그 상태에서 브라우저로 http://localhost:8000 접속하면 됨.

- hand_camera.py
    아두이노/웹앱과는 상관없는 독립적인 파이썬 테스트 스크립트. OpenCV
    창을 하나 띄워서 손가락이 얼마나 구부러졌는지(%) 화면에 숫자로
    보여주기만 함. 손 인식이 잘 되는지 웹앱 만들기 전에 빠르게 확인해
    보려고 만든 것 (개발 초기 실험용, 지금 시연에는 안 씀).

- README.md
    이 프로젝트 전체를 처음 보는 사람을 위한 설명서. 시스템 구조, 폴더
    구조, 안전 관련 주의사항, 실행 방법이 정리되어 있음.

- 열기_안내.txt
    이 zip을 처음 받는 사람을 위한 아주 짧은 "여는 법" 요약.

(참고: 예전엔 구버전 앱을 파일 하나로 통째로 번들링한 ems_demo_standalone.html
과, 8월 23일 시점 옛날 스냅샷 통째를 담은 mediapipehand/ 폴더도 "참고용"으로
같이 두었는데, 최종 기록/포트폴리오 목적에는 혼동만 준다고 판단해서 정리
과정에서 삭제했음. 필요하면 git 히스토리에서 복원 가능.)


====================================================
■ 폴더로 정리되어 있는 것들
====================================================

- docs/
    대회 제출용 정식 보고서, 전시 판넬(A2) PDF, 설계 정리 문서, 시연 대본
    및 예상 질문 정리, 시연할 때 패치 붙이는 위치 사진, 개발 커밋 히스토리
    원문 정리본, 팀 카톡 대화 기반 프로젝트 진행 타임라인 등 "문서" 모음.

- hardware/case/
    보드를 담는 케이스 3D 프린팅 설계 파일(.stl 3개)과 조립 과정 영상.
    3D 프린터용 슬라이서 프로그램(예: Cura)으로 .stl을 열면 출력할 수
    있음.

- firmware/openemsstim_serial_controller/
    지금 실제 아두이노 보드에 올라가 있는 최신 펌웨어 코드. 아두이노
    IDE로 이 폴더 안의 .ino 파일을 열어서 보드에 업로드하면 됨. 웹앱
    (app.js)이 보내는 PING/ARM/SET/STOP 같은 명령어를 알아듣는 코드가
    들어있음.

- firmware/channel_alternate_test/
    채널1/채널2가 보드의 어느 핀에서 실제로 나오는지 확인할 때 썼던
    진단용(테스트용) 펌웨어. 실제 시연용 펌웨어 아님.

- python-ems_closed_loop/
    지금의 웹앱(index.html+app.js)을 만들기 전에, 똑같은 "목표값 추종
    폐루프 제어" 아이디어를 먼저 파이썬(Tkinter 창 프로그램)으로 구현해
    본 초기 버전. 지금은 안 쓰지만, 아이디어가 처음 어떻게 구현됐는지
    보여주는 개발 기록으로 남겨둠.

- archive/early_prototypes/
    지금 구조(웹캠+웹앱+아두이노)로 정하기 전, 아예 다른 방식으로
    시도했던 초기 하드웨어 실험 2개:
      · EMS_FES_Feedback_Glove/ → 장갑 형태로 만들어보려 했던 초기 시도
      · fist_btn/ → 주먹을 인식해서 버튼처럼 쓰려던 초기 실험
    둘 다 지금 프로젝트와는 직접 연결 안 되고, 개발 히스토리 보존용.

====================================================
■ 결론: 실제로 시연/사용할 때 필요한 최소 구성
====================================================

index.html + app.js + hand_landmarker.task + pose_landmarker_full.task
+ run_server.bat  (+ 아두이노에는 firmware/openemsstim_serial_controller/
가 이미 올라가 있어야 함)

나머지(docs, hardware, archive, python-ems_closed_loop)는 전부
"참고/기록/포트폴리오용"이지 실제 동작에는 필요 없음.
